# 실시간 시세 (2026-09-28)

| 이전 문제 | 원인 | 지금 |
|---|---|---|
| 오래된 시세가 `N/A · 오래됨`으로 사라짐 | 분석 파이프라인이 STALE 가격을 `None`으로 바꾸고, 화면이 그 값만 표시 | 화면의 현재가는 앱 공용 시세 스토어에서 옴. 분석이 쓰지 않은 오래된 시세도 "분석 기준가 … (오래된 시세 — 판단에 미사용)"으로 남김 |
| 장전에도 20분 규칙 → 전일 종가만 있는 종목이 사라짐 | 같은 규칙이 "표시"와 "판단"에 함께 쓰임 | 판단 규칙(20분)은 그대로. 표시는 "장전 체결 미수신 · 직전 체결가"로 가격과 실제 체결 시각을 유지 |
| 화면이 분석 시점 가격을 현재가처럼 표시 | 현재가 = 저장된 분석 가격 | 최신 시세와 분석 기준가(가격·시각·품질)를 나란히, 따로 표시 |
| 재시작 후 같은 옛 가격으로 재판정 | 캐시된 시세가 분석 가격보다 새것인지 확인하지 않음 | 추천 재확인은 분석 기준 시각보다 **새로운** 체결가가 있을 때만 통과(`recommendation_freshness(analysis_price_ts=…)`) |

## 구조

```
Finnhub WebSocket (체결)  ──1개 연결──▶ FinnhubStream ──▶ QuoteHub (메모리, 종목별 최신 체결)
Finnhub REST /quote (구독 시 1회, 이후 ≥5분 간격, 스트림 체결이 없을 때만) ─┘      │
                                                         /api/quotes/stream (SSE, 50ms 묶음)
                                                                    │  (창마다 1개)
                                                     frontend quotes.ts (공용 스토어)
                                                     └ LivePrice (종목별 구독 → 그 칸만 다시 그림)
```

- **구독**: 보고 있는 종목(상세 화면, 90초 임대) → 보유 종목 → 관심 종목 순, 한도(`QUOTE_STREAM_MAX_SYMBOLS`, 기본 50) 초과분은 "구독 한도 초과"로 표시.
- **순서**: 더 오래된 체결은 버림(개수 집계), 같은 가격의 새 체결은 체결 시각 갱신, 동일 체결(시각·가격·수량)은 중복으로 집계. 클라이언트도 서버 `version`이 더 큰 행만 반영.
- **피드 분리**: 스트림 체결과 REST 스냅샷은 합치지 않음. 화면은 어느 피드인지 표시.
- **재연결**: 오류·45초 무응답 → 지수 백오프(1→60초, 지터) 후 재연결·전체 재구독. 클라이언트는 `online`/화면 복귀 시 즉시 재연결.
- **분석과 독립**: 체결은 분석·재무 조회·스캔을 시작하지 않고 DB에 쓰지 않음.
- **안전 한도 불변**: 표시용 가격은 "참고"이며, 매수 판단·수량 계산은 기존 신선도 규칙(20분)을 그대로 따름.

## 상태 표시

| 상태 | 뜻 |
|---|---|
| 실시간 수신 중 | 스트림 연결, 현재 세션 체결이 60초 이내 |
| 연결됨 · 최근 체결 없음 | 스트림 연결, 마지막 체결이 60초보다 오래됨 |
| 지연 시세 | 스트림이 아닌 REST 스냅샷 값 |
| 장 마감 · 마지막 체결가 | 장이 닫혀 있음 |
| 장전/시간외 체결 미수신 · 직전 체결가 | 현재 세션 체결이 아직 없음 — 가격은 이전 세션 값 |
| 연결 끊김 · 재연결 중 | 가격·시각은 마지막 값 그대로 유지 |
| 아직 미수신 / 수신 실패 | 받은 값 없음 |
| 구독 한도 초과 | 스트림 구독 대상이 아님 |

## 설정

- `FINNHUB_API_KEY`(무료 키) — 있으면 LIVE 모드에서 스트림 사용.
- `QUOTE_STREAM_MAX_SYMBOLS`(기본 50), `MARKETLENS_LIVE_QUOTES=0`으로 끄기.

## 제공 범위(확인된 것 / 확인 못 한 것)

- Finnhub 공식 문서 페이지는 개발 샌드박스에서 접속이 차단되어 원문을 확인하지 못함. 무료 계정의 거래소 범위·SIP 통합 여부·동시 구독 한도(제3자 자료상 50)는 **미확인**. 그래서 화면에 "미국 통합 시세"라고 표시하지 않음.
- 실제 수신 여부·지연·세션별 수신은 `quote-soak` 워크플로(LIVE) 결과로만 판단 — 결과는 아래 측정 절.
