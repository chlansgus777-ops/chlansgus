# 오늘의 브리핑

소유자 요청(2026-09-29): 처음에는 "아침 브리핑(한국시간 오전 7시)"이었다가, "고정되어 있으면 도움이 안 돼 — 오늘의 브리핑으로 바꾸고 실시간으로"로 바뀌었습니다. PC 앱 안에서만 보여 줍니다.

## 언제

- 홈 맨 위에 항상 있습니다. 3초마다 새로 받습니다.
- 시장·계좌·보유 종목 등락은 실시간 가격(토스 1초, 정규장 스트림)과 직전 종가를 비교합니다. 실시간 가격이 없으면 저장된 종가로 계산하고 "종가 기준"이라고 적습니다.

## 무엇을

| 칸 | 내용 | 자료가 없을 때 |
|---|---|---|
| 시장 | S&P 500(SPY), 나스닥 100(QQQ)의 직전 거래일 대비 종가 등락 | "자료 없음", "종가 없음" |
| 내 계좌 | 보유 미국 주식의 그 거래일 등락 합계(달러, %) — 종목별 (종가 − 전일 종가) × 보유 수량 | "보유 종목 없음", "등락 계산 불가", 가격을 확인한 종목 수 |
| 많이 움직인 종목 | 등락 폭이 큰 보유 종목 3개 | 표시 안 함 |
| 확인할 보유 종목 | 손절 기준 3% 이내 또는 아래, 1차 목표 3% 이내 또는 도달 | 표시 안 함 |
| 오늘·내일 일정 | 내 보유·관심 종목의 일정, 시장 전체의 중요 일정(중요도 0.7 이상) | 일정 자료를 못 받았으면 카드 아래 메모에 적음 |
| 매수 후보 | 마지막 스캔의 매수 계열 상위 3개 | 표시 안 함 |
| 밤사이 알림 | 최근 24시간의 실시간 판단 알림(브리핑 알림 자신은 빼고) | 표시 안 함 |

- **기준 거래일:** 기준 거래일은 끝난 미국 거래일입니다. 그 거래일의 일봉이 아직 저장되지 않았으면 저장된 가장 최근 거래일로 계산합니다. 이때 "9/25 종가가 아직 저장되지 않아 9/24 종가 기준입니다"처럼 적습니다. 오래된 숫자를 새 숫자처럼 보이지 않게 하기 위해서입니다.
- **계산 방식:** 계산은 읽기만 합니다. 스캔이나 외부 요청 폭주를 일으키지 않습니다. 한 번 만든 브리핑은 3초 동안 다시 씁니다. "새로 고침"을 누르면 다시 계산합니다.
- **코드와 테스트:**
  - 코드: `backend/marketlens/application/briefing.py`, `GET /api/briefing`, `frontend/src/components/Briefing.tsx`
  - 테스트: `tests/integration/test_briefing.py`, `components/briefing.test.tsx`
