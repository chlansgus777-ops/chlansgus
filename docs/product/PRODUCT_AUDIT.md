# MarketLens 제품 점검과 개편안 (2026-09-28)

## 점검 방법

MOCK 백엔드를 새 데이터 폴더로 실행하고, Vite 개발 화면을 Playwright로 열었습니다. 창 크기는 1440×900과 760×900입니다. 점검 순서는 다음과 같습니다.

1. 최초 실행
2. 시장 스캔 1회(7.9초, 후보 40, AI 호출 145회, 모의 포지션 16개)
3. 보유 종목 2개와 현금 입력
4. 관심 종목 1개 추가
5. 모든 메뉴 방문

화면마다 요청 수와 응답 시간, 가로 스크롤, 페이지 높이를 기록했습니다. 코드 주석과 이전 보고서의 평가는 사실로 보지 않았고, 실제 화면과 API 응답으로만 판단했습니다.

LIVE는 공급자 키가 없는 환경이라, 실데이터 호출 대신 테스트용 LIVE 픽스처와 '설정 필요' 상태만 확인했습니다.

## 화면별 발견

| 화면 | 답하는 질문 | 확인한 문제 |
|---|---|---|
| 홈 | 오늘 무엇을 볼까 | 같은 크기의 카드 12개가 반복되어 무엇을 먼저 읽을지 알 수 없습니다. 첫 실행 때는 빈 상자 7개가 나열됩니다. 시스템 상태는 영어 공급자 이름(universe, price…)으로 표시됩니다. 사이드바 배경이 첫 화면 높이(900px)에서 끊깁니다. |
| 기회 찾기 | 어떤 종목이 조건을 통과했나 | 1440px에서도 표가 잘려 '현재 유효' 열이 보이지 않습니다. 세션('프리마켓')과 '지연(DELAYED)' 같은 값이 모든 행에 똑같이 반복됩니다. 행 하나만으로는 왜 이 종목인지 알 수 없습니다. |
| 종목 분석 | (위와 같음) | 스캔 후보 표 40행을 **통째로 한 번 더** 보여줍니다. 관심 종목은 'N/A · 분석 전'으로만 나오고, 그 자리에서 분석할 수 없습니다. |
| 종목 상세 | 사도 되나, 얼마에, 무엇을 조심하나 | 아래 '분석 내용' 절 참고. 차트는 폭이 좁은 보조 카드여서 시선의 중심이 되지 못합니다. 번호 붙은 여덟 절이 모두 같은 무게로 나열됩니다. |
| AI 위원회(메뉴) | AI는 어떻게 봤나 | 후보를 고르면 상세 화면의 위원회 카드와 같은 내용이 나옵니다(중복). LIVE 기본값에서는 LLM이 '없음'이라 사용할 수 없습니다. |
| 포트폴리오 | 내 계좌는 괜찮나 | 보유 종목 목록이 맨 아래 접힌 칸에 숨어 있습니다. 수동 입력과 거래 기록이라는 두 가지 입력 방식이 설명 없이 나란히 있습니다. 해석에서는 'NVDA 44% 한도 초과'를 경고하는데 카드는 '분산 정도: 보통'으로 표시해 서로 다른 신호를 줍니다. |
| 시장 이슈 / 시장·거시 | 시장에 무슨 일이 있나 | 같은 목적의 메뉴가 둘로 나뉘어 있습니다(이슈·일정 / 거시). 이슈 표는 좋은 편입니다(사실과 해석을 구분). |
| 성과 분석 | 추천이 맞았나 | 표본이 0일 때도 N/A로 채운 표 여섯 개가 나옵니다. IC/IR 표와 가중치 보정 같은 연구 도구가 첫 화면에 있습니다. 스캔 때 모의 포지션 16개를 열었지만 '갱신'을 누르기 전까지 0으로 보입니다. |
| 시스템 상태 | 데이터가 믿을 만한가 | 공급자 표 두 개와 LLM 사용량. 내용은 진단용이며, 영어 식별자가 그대로 나옵니다. |
| 설정 | 어떻게 설정하나 | 입력칸 폭이 서로 다릅니다. 설정 파일 원문(영어 키, JSON)이 길게 나열됩니다. AI 공급자 설정과 자동 갱신(스케줄러) 설정이 없습니다. |

공통으로 확인한 문제는 다음과 같습니다.

- 상단 상태 줄에 칩이 최대 8개 있어 두 줄로 넘칩니다.
- 모든 영역이 같은 테두리 카드라 강약이 없습니다.
- 빈 상태, 오래됨, 실패의 모양이 비슷합니다.
- 가로 스크롤은 없습니다. 760px에서 종목 상세 높이는 4,710px입니다.

## 분석 내용(종목 상세)의 부족

분석 결과(API)에는 다음 정보가 이미 있습니다.

- 실적 서프라이즈와 가이던스, 추정치 변화(7/30/90일)
- 자기 과거·동종업계 대비 밸류에이션
- 가격 계획의 계산 근거
- 투자 논리 철회 조건, 데이터 신선도, 증거 136개

그러나 화면은 이 정보를 사용자의 질문으로 엮지 못합니다.

| 질문 | 현재 화면 | 결정 |
|---|---|---|
| 최근 무엇이 달라졌나 | '지난 분석과 비교'가 접혀 있고 첫 분석이면 한 줄뿐입니다. 실적·추정치·가격 변화는 8번 상세 자료에 흩어져 있습니다. | 날짜가 붙은 변화 목록으로 모읍니다: 지난 분석 대비, 최근 실적, 30일 추정치, 1·3개월 가격(시장 대비). |
| 왜 중요한가 | 없음 | 각 변화에 '→ 어떤 점수·가격 판단에 어떻게 작용했나'를 숫자로 연결합니다. |
| 지지·반대 근거 | '좋은 이유'(점수 사유)만 있고 반대 근거는 '위험' 절에 한 줄뿐입니다. | 지지와 반대를 나란히 두고, 각각 출처와 기준 시각을 붙입니다. |
| 가격을 어떤 계산으로 평가했나 | 규칙 문자열 4개(최대 매수가 = 역산 등)가 상세 자료 안에 있습니다. | 밸류에이션(핵심 배수, 자기 과거 백분위, 동종 중앙값, 이익수익률 − 금리)과 가격 계획 식(손절 = 지지선 − 0.5ATR, 최대 매수가 = (목표 + 2×손절)/3)을 실제 숫자로 보여주고, 가정과 한계를 함께 적습니다. |
| 무엇을 모르나, 무엇이 바뀌면 판단이 바뀌나 | 부족 데이터 목록과 논리 철회 조건이 서로 다른 절에 있습니다. | 모르는 것마다 영향과 해결 방법을 적습니다. 판단 전환 조건은 가격(손절·최대 매수가), 점수(매수 해제 기준), 논리 조건, 다음 일정, 추천 만료로 정리합니다. |

이 정리는 분석을 다시 계산하지 않고, 저장된 분석 스냅샷에서 **결정론적으로** 만듭니다(`application/brief.py`). 오래된 추천에도 똑같이 적용됩니다. 문장은 해당 종목의 숫자로만 만들고, 사실, 계산, 해석, 가정을 표시해 구분합니다.

## AI 위원회의 실제 가치

코드를 따라가며 확인한 구조는 다음과 같습니다(`application/committee/orchestrator.py`).

- 14번 호출 중 행동이나 규모를 바꿀 수 있는 것은 리스크 매니저와 포트폴리오 매니저 **2번**뿐입니다.
- 분석가 7명은 역할별로 걸러낸 **같은 결정론적 증거**를 받아 다시 요약합니다.
- 강세·약세 토론 2라운드와 종합자는 신뢰도 보정(최대 ±10)과 글에만 영향을 줍니다. 그런데 신뢰도는 상승 확률이 아니라고 화면이 스스로 밝히고 있습니다.
- 결정론적 모델이 읽지 못하는 자료는 **뉴스 원문 하나**(news 분석가)뿐입니다.
- 무료 조건(유료 요금제 미사용)의 LIVE 기본값에서는 LLM이 '없음'이라 기능 전체가 비활성입니다.

**결정: 축소·통합합니다.**

AI 검토는 원문 뉴스를 읽는 역할, 하향 전용 리스크 검토, 비중 조언의 3번 호출로 줄입니다. 분석가 6명, 토론, 종합자를 제거합니다(호출 수 14→3, 상위 후보 20개 기준 145→60).

- 결과는 상세 화면의 한 영역에만 표시합니다. 독립 메뉴는 제거합니다.
- 설정에서 무료 로컬 모델(OpenAI 호환 주소, 예: Ollama)을 연결할 수 있게 합니다.
- 안전 장치(증거 ID 검증, 숫자 대조, 프롬프트 주입 탐지, 하향 전용)는 남은 역할에 그대로 적용합니다.

## 기능 정리

| 기능 | 결정 | 이유 |
|---|---|---|
| 홈 | **유지·재구성** | 대표 판단 1개와 행동 목록(검토할 후보, 내 보유 경보, 관심 종목 변화, 데이터 상태)으로 강약을 둡니다. |
| 기회 찾기 + 종목 분석 | **통합 → '종목'** | 같은 스캔 표가 두 번 나옵니다. 하나의 화면에 검색·분석, 후보, 관심 종목을 탭으로 둡니다. |
| 관심 종목 | **유지·이동** | 종목 화면의 탭으로 옮기고, 행에서 바로 분석하게 합니다. |
| 종목 상세 | **유지·재설계(대표 화면)** | 판단 → 무엇이 달라졌나/근거 → 위험과 모르는 것 → 상세 자료 순서로 바꿉니다. 차트를 시각적 중심으로 둡니다. |
| 포트폴리오 + 거래 기록 | **유지·재구성** | 보유 목록을 맨 위로 올리고 입력은 한 곳으로 모읍니다. 수동 입력은 '거래 기록이 없는 종목용'으로 명시합니다. |
| 시장 이슈 + 일정 + 거시 | **통합 → '시장'** | 목적이 같은 세 화면을 탭 하나로 묶습니다. |
| 성과 분석 | **유지·단순화** | 표본 수, 모의 계좌, 결과를 먼저 보여줍니다. IC/IR·가중치 보정은 '연구용'으로 접고, 표본이 없으면 표 대신 '표본 n/필요 N'을 표시합니다. |
| AI 위원회 메뉴 | **제거** | 상세 화면과 중복됩니다. |
| AI 위원회 7인·토론·종합 | **축소(3역할)** | 위 절 참고 |
| 시스템 상태 | **이동 → 설정 '연결 상태'** | 진단용이라 첫 메뉴에 둘 필요가 없습니다. 영어 식별자는 한국어 이름으로 표시합니다. |
| 설정 | **재구성** | 목적별로 묶습니다: 데이터 연결, 자동 갱신, AI 검토, 표시. 모델 설정 원문은 '읽기 전용 모델 설정'으로 접습니다. |
| 가이드(용어) | **유지** | 용어 팝오버가 있어 메뉴 대신 상단 도움말로 연결합니다. |
| 쉽게/자세히 보기 전환 | **제거** | 정보를 숨기는 전환 대신, 상세 자료를 절 단위로 접습니다. |
| 대시보드의 '분석 범위', '추천이 바뀐 종목' | **통합** | 홈의 데이터 상태와 후보 영역에 흡수합니다. |

보존하는 사용자 데이터는 다음과 같습니다. 저장 구조는 바꾸지 않습니다. AI 위원회 결과의 기존 기록도 그대로 읽힙니다.

- 보유 종목, 거래 기록, 관심 종목
- 설정, 분석 이력(추천·위원회 기록 포함)

## 핵심 사용 흐름

1. 처음 실행하면 데이터 모드와 키를 설정합니다(LIVE). 이어서 데이터 준비를 하며 진행 상태를 봅니다.
2. 홈에서 오늘의 대표 판단, 지금 유효한 후보, 내 보유 경보를 봅니다.
3. 종목 화면에서 후보를 고르거나 원하는 종목을 검색해 분석합니다.
4. 종목 상세에서 판단, 근거, 위험을 확인하고 관심 종목에 저장하거나 매수 금액을 확인합니다.
5. 포트폴리오에 거래를 기록하면 보유와 한도에 반영됩니다.
6. 성과 화면에서 추천 결과와 모의투자를 다시 확인합니다.

메뉴는 5개입니다: 홈, 종목, 포트폴리오, 시장, 성과. 설정은 하단에 둡니다.

## 디자인 방향

세 가지 방향을 비교했습니다.

1. **현재 방식을 다듬기**: 같은 카드 격자를 유지하는 방식입니다. 강약을 만들 수 없어 제외했습니다.
2. **밝은 금융 리포트형**: 긴 글을 읽기에는 좋습니다. 하지만 차트와 가격 계획이 주인공인 도구에서는 시선을 모으는 장면을 만들기 어렵습니다.
3. **'관측 장비(Instrument)'형 어두운 테마 (선택)**
   - 배경은 깊은 남색 계열 3단(배경, 표면, 떠 있는 표면)입니다.
   - 핵심 장면(판단 헤드라인, 가격 계획 차트, 선택된 후보)에만 빛 번짐과 그라데이션을 씁니다.
   - 읽는 영역(근거, 표)은 테두리 없는 면과 넓은 행간으로 차분하게 둡니다.
   - 판단 색은 의미별로 고정합니다: 매수(청록), 소량(하늘), 대기(호박), 관찰(보라 회색), 매도(주홍).
   - 판단은 색과 함께 반드시 단어와 기호로 표시합니다.

차트는 이 제품의 시각적 중심입니다.

- 가격선과 영역 그라데이션 위에 가격 계획을 **구간 띠**로 겹칩니다: 매수 구간, 손절 아래, 목표.
- 축, 격자, 현재가 표식, 호버 십자선, 툴팁(날짜·종가·계획 대비 거리)을 갖춥니다.
- 동작은 150–250ms의 짧은 전환입니다. `prefers-reduced-motion`이면 모두 끕니다.
