# 토스증권 계좌 연결 (조회 전용, 2026-09-29)

소유자 요청: "토스 API를 활용하는 방법이 있어? 내가 토스증권에서 거래하거든" → "1번(계좌 읽기 전용 동기화)부터 꼼꼼하게".

## 무엇을 하나
- 토스증권 오픈API로 **보유 주식·평균 매입가·예수금·체결 내역을 읽어** 포트폴리오를 자동으로 맞춥니다.
- **주문 기능은 없습니다.** `providers/live/toss.py`에는 토큰 발급 외에 GET 요청만 있습니다. 테스트가 주문·정정·취소 경로가 없는지 확인합니다.
- 실데이터(LIVE) 모드에서만 켤 수 있습니다. 모의 가격으로 실제 계좌를 평가하면 틀린 숫자가 나오기 때문입니다.

## 근거로 삼은 명세
- 토스증권 공식 OpenAPI 3.1 명세 **v1.2.17**을 따랐습니다.
  - 원본 주소: `https://openapi.tossinvest.com/openapi-docs/latest/openapi.json`
  - 이 작업 환경에서는 토스 도메인에 접속할 수 없었습니다. 그래서 공개 npm 패키지 `tossinvest-openapi-mcp` 0.2.0(2026-09-28)에 들어 있는 명세 사본을 사용했습니다.
- 쓰는 엔드포인트만 `backend/tests/fixtures/toss/spec_subset.json`에 고정해 두었습니다.
- 테스트용 가짜 서버(`backend/tests/toss_fake.py`)는 두 가지를 이 명세로 검사합니다. 명세와 어긋나면 테스트가 실패합니다.
  - 받은 요청마다 필수 파라미터·헤더가 있는지
  - 보내는 응답마다 스키마에 맞는지

| 쓰는 API | 용도 |
|---|---|
| `POST /oauth2/token` | 접속 토큰 발급(client credentials) |
| `GET /api/v1/accounts` | 종합매매 계좌의 `accountSeq` 조회 |
| `GET /api/v1/holdings` | 보유 종목·수량·평균 매입가·평가·손익 조회(국내·미국) |
| `GET /api/v1/buying-power?currency=USD/KRW` | 현금 매수 가능 금액 조회 |
| `GET /api/v1/exchange-rate` | 참고 환율(원화 예수금 환산용) |
| `GET /api/v1/orders?status=CLOSED` | 체결 내역(100건씩 페이지로) |

## 명세의 주의점과 대응
- **토큰은 키 하나에 1개만 유효합니다.** 새로 발급하면 이전 토큰이 즉시 무효가 됩니다.
  - 토큰은 만료 5분 전까지 재사용합니다.
  - 발급은 잠금 안에서만 합니다. 스레드 둘이 동시에 발급하면 서로의 토큰을 무효로 만들기 때문입니다.
  - 401을 받으면 한 번만 다시 발급합니다. 그래도 401이면 "같은 키를 다른 프로그램에서 쓰고 있음"이라고 안내합니다.
- **허용 IP 목록이 있습니다.** 등록하지 않은 IP에서 호출하면 403입니다. 이때 "WTS 설정 > Open API > 허용 IP 관리에 이 PC의 공인 IP 등록"이라고 안내합니다.
- **요청 한도(429)**: `Retry-After`만큼 최대 두 번 기다립니다. 5초가 넘게 기다리라고 하면 바로 포기하고 다음 주기에 다시 시도합니다.
- **금액이 모두 문자열(decimal)입니다.** Decimal로 읽습니다. 숫자가 아니거나 형식이 틀리면 추측하지 않고 "응답 해석 실패"로 처리합니다.
- **모르는 값(enum)이 올 수 있습니다.** 미국·국내가 아닌 항목은 버리지 않고 "분석에서 뺐다"고 알립니다.
- **체결 목록의 한계**: 오픈API로 넣을 수 없는 시간외 종가 주문은 명세상 목록에 나오지 않습니다. 화면에도 그렇게 적어 두었습니다.

## 포트폴리오 반영 규칙 (`domain/broker.py`)
1. **토스 계좌에 있는 미국 주식**은 토스의 수량·평균 매입가를 그대로 씁니다.
   - 같은 종목의 직접 입력 줄과 거래 기록은 계산에 쓰지 않고, 그 사실을 안내에 적습니다.
   - 거래 기록의 실현 손익·배당은 그대로 이어 붙입니다.
   - 겹친 직접 입력 줄은 "지우기" 버튼으로 정리할 수 있습니다.
2. **토스에 없는 보유**(직접 입력·거래 기록)는 그대로 둡니다. 다른 증권사 보유일 수 있기 때문입니다.
   - 대신 "토스에 없음" 표시와 "판 종목이면 지우세요" 안내를 붙입니다.
3. **국내 주식**은 따로 "국내 주식 (토스증권)" 표에 원화로 보여 줍니다.
   - MarketLens는 미국 주식만 분석하므로 달러 합계·비중·매수 수량 계산에는 넣지 않습니다.
4. **현금**은 설정에 따라 셋 중 하나입니다. 기본값은 토스 달러 예수금입니다.
   - 토스 달러 예수금
   - 달러 + 원화 예수금 (원화는 토스 참고 환율로 환산)
   - 직접 입력한 현금
5. **토스 보유 종목은 이 화면에서 수정·삭제할 수 없습니다.** 지워도 다음 동기화에 다시 나타나기 때문입니다. 대신 "자동"이라고 표시합니다.

## 동기화
- **시점**
  - 연결 직후 한 번
  - 미국장(프리마켓·정규장·애프터마켓)이나 한국장(평일 08:30–16:00 KST)이 열려 있으면 **1분마다**
  - 그 밖에는 10분마다
  - "지금 동기화"를 누르면 바로
- **방식**: 앱이 열려 있는 동안 실시간 스트림의 5초 신호가 백그라운드에서 동기화를 실행합니다. 요청 화면이 기다리지 않습니다.
- **실패했을 때**
  - 마지막으로 받은 보유 현황을 **받은 시각과 함께** 그대로 보여 줍니다. 새것처럼 보이게 하지 않습니다.
  - 키·IP 문제는 10분마다, 그 밖의 실패는 1분마다 다시 시도합니다.
- **보유나 현금이 바뀌면** 버전이 올라갑니다. 그러면 아래가 모두 버튼 없이 따라옵니다.
  - 실시간 판정의 보유 표시
  - 시세 구독
  - 열려 있는 포트폴리오·홈·종목 화면

## 키 보관
- 입력한 키는 **먼저 토스에 접속해 계좌를 확인한 뒤에만** 저장합니다. 틀린 키는 저장하지 않습니다.
- 저장 위치
  - Windows 자격 증명 관리자(`keyring`)
  - 그것이 없을 때만 이 PC의 MarketLens 전용 설정 파일(.env)
  - Windows 빌드는 `keyring`을 함께 묶습니다. 빌드 검사가 자격 증명 관리자(`WinVaultKeyring`)를 쓰는지 확인하고, 아니면 실패합니다.
- 키와 발급된 토큰은 로그 가리기 목록에 등록합니다. 계좌번호는 뒤 4자리만 화면에 보냅니다.
- 일반 "초기 설정" 칸으로는 토스 키를 저장할 수 없습니다. 연결 확인을 거치지 않기 때문입니다.
- "연결 해제"를 누르면 아래를 지웁니다. 직접 입력한 보유와 거래 기록은 그대로입니다.
  - 키(자격 증명 관리자와 .env)
  - 토스에서 받은 보유·체결 기록
