# 성능 개선 (2026-09-28) — 측정 전후 비교

## 측정 방법
- **데이터**: 실제 규모의 안전한 복제본(스크래치 DB, 888 MB)
  - 가격 바 3,162,000행, 종목 6,000개
  - 스캔 60회 · 추천 2,400건(추천 1건당 분석 JSON 약 190 KB)
  - 보유 4종목, 관심 종목 7개
- **외부 공급자**: 모두 "느리고 실패함"으로 대체했습니다(요청마다 3초 뒤 실패). 실데이터는 쓰지 않았고, 실제 네트워크 연결도 없습니다.
- **API 측정**: 앱 수명주기를 켠 상태(시세 워커 동작)에서 엔드포인트마다 첫 요청 1회와 반복 3회를 쟀습니다.
- **브라우저 측정**: 빌드한 화면을 실제 Chromium(헤드리스)으로 열고 실제 HTTP 백엔드에 붙였습니다.
  - 시세 스트림은 **합성 체결**(초당 20건, 가격은 가짜)로 부하만 줬습니다.
  - 메뉴를 30분 동안 계속 왕복했고, 중간 10분은 데이터 쓰기 부하(3초마다 3,000종목 하루치)를 함께 걸었습니다.
- **전(before)**: 커밋 e8610d3(성능 작업 전). **후(after)**: 현재 브랜치.

## 첫 요청과 캐시 적중
- **서버 쪽**: 외부 자료는 한 키에 백그라운드 작업 하나만 돌고, 동시에 같은 요청이 와도 작업 하나를 공유합니다. 실패하면 이전 정상값과 실패 사실을 함께 보여 주고, 2분 뒤에 다시 시도합니다.
- **화면 쪽(앱 전체 캐시)**:
  - 재방문하면 마지막 응답을 **실제 받은 시각과 함께** 바로 보여 주고, 요청 1개로 새로 받습니다.
  - 같은 요청은 합칩니다.
  - 아무도 보지 않는 요청은 취소합니다.
  - 변경(거래·보유·관심 종목·스캔·데이터 준비) 전에 시작된 응답은 버립니다.
  - 종목·기간 같은 조건이 다르면 절대 재사용하지 않습니다.

## 사용자 보고 문제
- **후보 표가 전부 "데이터 부족·오래됨·거부권"**:
  - 오류가 아닙니다. 스캔 시각(미국 프리마켓 등)에 20분 안의 체결가가 없어서, 안전 규칙에 따라 판단을 보류한 것입니다.
  - 이제 표 위에 **한 번만** 이유와 할 일(정규장에 다시 스캔)을 설명하고, 줄마다 반복하던 배지는 뺐습니다.
- **포트폴리오의 "수동 입력 줄은 쓰지 않습니다"가 계속 떠 있음**:
  - 거래 기록이 있는 종목은 거래 기록으로 계산하기 때문에 나오던 문구입니다.
  - 이제 겹친 종목을 한 번에 알려 주고 **"직접 입력한 줄 지우기"** 버튼을 둡니다.
  - 보유 표 각 줄에 **빼기**(직접 입력한 줄) / **매도 기록**(거래 기록 기준 보유) 버튼을 넣었습니다.
- **"가격 이력 263/263"에서 10분 멈춤**:
  - 가격 단계가 끝난 뒤 진행률을 보고하지 않는 긴 단계들이 있었습니다(SEC 종목 목록, 주식분할, 추정치, 발행주식수, 개별 확인).
  - 이제 모든 단계가 시작할 때부터 표시되고, 몇 분째인지 나옵니다.
  - 예상보다 오래 걸리면 "1분 미만" 대신 "남은 시간 계산 중"으로 표시합니다.

## 충족하지 못했거나 확인하지 못한 것
- **포트폴리오 재방문 1회 표본 228 ms**(목표 200 ms). 메뉴 선택 표시도 181 ms였습니다. 30분 반복 측정에서는 p50 72 ms · p95 140 ms라 대부분 충족하지만, 최대값은 311 ms입니다.
- **브라우저 프로세스 메모리 944 MB → 1.4 GB** (헤드리스 Chromium, 클릭 14,105회). 페이지의 JS 힙과 DOM은 평탄해서 앱 객체가 쌓인 것은 아니고, 브라우저 내부 캐시로 보입니다. 다만 **실제 Windows WebView2에서는 확인하지 못했습니다.**
- **실데이터 공급자(FRED, Finnhub, Polygon, SEC)의 실제 지연과 네트워크 복구**는 이번에 측정하지 않았습니다. 모두 "느리고 실패"로 대체했습니다. 시세 스트림 재연결은 이전 실측 1.43초입니다(`REALTIME_QUOTES.md`).
- **데이터 준비 단계 표시**는 테스트로만 확인했습니다. 실제 10분짜리 준비 작업으로 다시 재지 않았습니다.
- **Windows 설치본 실행 체감 속도**는 이 환경에서 확인할 수 없습니다.
