# 실시간 동작 (2026-09-29)

소유자 요청: "주식 프로그램에 맞게 실시간으로, 1초 1초마다 내가 신경 쓰지 않아도 되는 프로그램".

## 토스증권 1초 시세 (2026-09-29 추가)
소유자 지적: "정규장에서만 실시간으로 보인다는거야?" — 맞았습니다. 무료 Finnhub는 정규장 체결만 줍니다. 그래서 프리마켓·애프터마켓·야간에는 화면이 전날 종가를 보여 줬고, 분석에는 현재가가 없었습니다.
- **동작**
  - 토스증권을 연결하면 토스 오픈API 현재가(`GET /api/v1/prices`, 한 번에 최대 200종목)를 **1초마다** 받습니다.
  - 시간대: 프리마켓, 정규장, 애프터마켓, 야간(주간거래) 모두입니다. 토스가 가격을 주는 시간이면 받습니다.
  - 주말·휴장에는 30초마다 받습니다.
- **대상 종목**
  - 순서: 보고 있는 종목 → 보유 → 관심 → 상위 매수 후보. 최대 200종목입니다(Finnhub 스트림만 쓸 때는 50종목).
- **분석이 쓰는 현재가**
  - 화면과 같은 토스 가격을 씁니다. 화면에 없는 종목은 분석할 때 토스에 한 번 바로 물어봅니다.
  - 그래서 "분석 때 현재가 없음"과 화면마다 가격이 다른 문제가 사라집니다.
- **자동 스캔**
  - 토스 시세가 들어오는 동안에는 프리마켓·애프터마켓에도 30분마다 돕니다.
  - 토스가 끊기면 정규장과 장 마감 뒤에만 도는 원래 규칙으로 돌아갑니다.
- **토큰**
  - 계좌 동기화와 같은 접속 토큰을 씁니다. 토스는 키 하나에 토큰 1개만 유효하기 때문입니다.
- **오류가 났을 때**
  - 키·IP 문제: 60초마다 다시 시도하고, 연결 카드에 이유를 보여 줍니다.
  - 요청 한도·서버 문제: 몇 초 뒤 다시 시도합니다.
  - 상태 표시줄에는 "실시간 · 토스 1초 · N/200" 또는 "토스 시세 끊김 · 다시 시도 중"이 뜹니다.
- **확인한 것**
  - 테스트: `tests/unit/test_toss_quotes.py`
  - 실사용 시나리오: 프리마켓 시각(한국 17:40)에 토스 명세대로 동작하는 가짜 서버로 확인했습니다. 상태 표시줄 "실시간 · 토스 1초", 종목 행 LIVE(PREMARKET), 분석 현재가 출처 toss.
- **확인하지 못한 것**
  - 실제 토스 서버에서 프리마켓·야간 가격이 오는지는 소유자의 키로 처음 연결할 때 확인해야 합니다.

## 무엇이 언제 바뀌나
| 대상 | 주기 | 방법 |
|---|---|---|
| 현재가 | 체결마다 (Finnhub 스트림) · 스트림이 끊기면 30초마다 | 앱 전체가 스트림 하나를 공유합니다. 체결이 오면 해당 종목 가격만 다시 그립니다. |
| 매수 구간·손절·목표·손익비 판정 | 체결마다 | 저장된 가격 계획(최대 매수가·손절·1차 목표)과 새 가격을 비교합니다(`application/live_judge.py`). 스캔은 필요 없습니다. |
| 알림 | 판정이 바뀌는 순간 | 경우는 아래 표와 같습니다. 알림은 화면 오른쪽 아래 팝업과 상태 표시줄의 종 아이콘으로 보여 줍니다. 설정에서 켜면 바탕화면 알림도 뜹니다. |
| 한 종목 재분석 | 자동 | 손절·목표가에 닿거나, 분석 때보다 가격이 ±5% 넘게 움직이면 그 종목만 다시 분석합니다. |
| 시장 전체 스캔 | 자동 | 정규장에는 30분마다, 장이 완전히 닫힌 뒤에는 종가 기준으로 1번 합니다. 끝나면 모든 화면이 저절로 바뀝니다. |
| 포트폴리오 | 체결마다 | 종목별 실시간 손익, 실시간 평가금액, 오늘 손익(전일 종가 대비)이 바뀝니다. |

**알림이 뜨는 경우**
| 경우 | 알림 수준 |
|---|---|
| 매수 구간에 들어옴 | 긍정 |
| 매수 구간에서 벗어남 | 참고 |
| 손절 기준에 닿음 | 보유 종목이면 위험, 아니면 주의 |
| 1차 목표가에 닿음 | 보유 종목이면 긍정, 아니면 참고 |
| 자동 재분석 결과 | 판정이 바뀌었으면 주의, 그대로면 참고 |

**화면별 표시**
- 홈 "실시간 신호" 카드
- 후보 표의 "현재 유효성" 열
- 종목 화면 맨 위 표시
- 관심 종목 표
- 보유 표

**자동 재분석 조건**
- 정규장이거나, 장이 완전히 닫혀 종가가 확정된 때만 합니다.
- 같은 종목은 30분에 1번까지, 전체는 1시간에 20번까지입니다(무료 요청 한도).

**자동 스캔 조건**
- 설정에서 끌 수 있습니다(`MARKETLENS_SCHEDULER=0`).
- 프리마켓·시간외에는 판단용 현재가가 없어 스캔하지 않습니다.
- 데이터 준비 전, 그리고 다른 스캔이나 데이터 준비가 도는 중에는 건너뜁니다.

## "지금 매수 구간"의 조건 (모두 만족해야 함)
1. 매수 계열 판정(매수·소량 매수·추가 매수)이고, 분석 데이터가 최신 또는 지연 품질일 것
2. 현재가 ≤ 최대 매수가, 현재가 > 손절 기준
3. 현재가 기준 손익비 ≥ 최소 손익비
4. 분석 이후 가격 변동이 허용 범위 안일 것
5. 현재가가 20분 안의 체결일 것. 장이 완전히 닫혔으면 마지막 종가도 인정합니다.

2~4는 추천 신선도 판정(`domain/freshness._revalidate`)과 같은 규칙입니다. 목록과 종목 화면이 서로 다른 답을 내지 않습니다.

## 한계 (무료 공급원)
- **동시에 실시간으로 볼 수 있는 종목은 50개입니다**(Finnhub 무료 스트림).
  - 우선순위는 보고 있는 종목 → 보유 → 관심 → 마지막 스캔의 상위 매수 후보 15개입니다.
  - 나머지 종목은 자동 스캔 주기로 갱신됩니다.
- **6,000여 종목 전체를 매초 판정하지는 않습니다.** 재무·실적처럼 천천히 바뀌는 부분은 스캔 때 계산하고, 가격에 따라 바뀌는 부분만 실시간으로 다시 판정합니다.
- **스트림이 끊기면 REST 시세로 대신합니다.** 종목당 약 30초 간격이고, 무료 요청 한도를 나눠 씁니다. 화면에는 "연결 끊김·재연결 중"이 표시됩니다.
- **프리마켓·시간외 체결은 무료 시세에 없습니다.** 그래서 그 시간에는 "지금 매수 구간"이 나오지 않습니다.
