# UI/UX 가이드라인

MarketLens 화면은 **"결론 → 이유 → 행동 → 근거"** 순서를 지킨다. 초보자가 첫 화면에서 알고 싶은 것은
“무엇을, 왜, 얼마에 사고, 무엇을 조심해야 하며, 지금 사야 하나 기다려야 하나”이다. 원본 데이터는 그 아래에 둔다.

## 원칙
1. **답을 먼저.** 종목 화면 최상단(hero)에 종목·현재가·거래 세션·가격 기준 시각(ET+KST)·최종 판정·점수·신뢰도·추천 유효 상태, 그리고 한 줄 결론.
2. **숫자 → 의미 → 행동.** 숫자만 두지 않는다. 예: `손익비 3.54 (2 이상이 기준)`, `현금이 3%뿐이라 새 종목은 소액만 가능합니다.`
3. **용어는 그 자리에서 설명.** 전문 용어는 `<Term k="…">`(점선 밑줄 + ⓘ)으로 감싸 이름·한 줄 뜻·왜 중요한지·좋은 방향을 툴팁으로 보여 준다. 사전: `frontend/src/glossary.ts`. 전체 목록은 `용어·판정 설명`(/guide).
4. **쉽게 보기 / 자세히 보기.** 기본은 쉽게 보기. 쉽게 보기에서는 원본 표·근거 ID 칩·버전 정보를 접어 둔다(`<More>`, `EvidenceChips`). 자세히 보기에서는 모두 펼친다. 선택은 브라우저에만 저장(실패해도 기본값으로 동작).
5. **없는 데이터는 없다고 말한다.** 가짜 값·0·빈칸으로 채우지 않는다. `데이터 부족`, `사용 불가(UNAVAILABLE)`, `오래됨(STALE)`을 문장과 배지로 표시하고 무엇이 부족한지 적는다.
6. **모의(MOCK) 명시.** MOCK 모드는 상단 배너 + 종목 화면 경고로 항상 보인다. 모의투자 성과는 “실제 수익이 아님”을 함께 쓴다.
7. **주문 없음.** 어떤 버튼도 실제 주문을 넣지 않는다. 버튼 문구는 행동을 설명한다(`분석 다시하기`, `관심종목 추가`, `AI 토론 자세히 보기`, `왜 바뀌었나요?`, `당시 분석 다시보기`).

## 화면 구조
- **대시보드 (3×3 카드):** ① 시장 분위기 · 유망 종목 · 조심할 위험 ② 다가오는 일정 · 내 포트폴리오 · 시스템 상태 ③ 모의투자 성과 · 추천이 바뀐 종목 · 관심 종목 알림.
- **종목 분석:** hero → [매수 계획 | 좋은 이유 | 주의할 이유] → [현재 이슈 영향(오늘/1~5일/2~6주) | 투자 논리가 깨지는 조건 | 내 포트폴리오에 넣어도 될까?] → 가격 차트(진입·손절·목표선) → 왜 이런 판단이 나왔나요? → 부족하거나 오래된 데이터 → AI 투자위원회 요약 → (자세히) 신선도·점수 구성·재무·거시·이슈·근거 원본.
- **AI 위원회:** 입장 요약 칩이 먼저, 강세/약세 논거와 전체 토론은 `AI 토론 자세히 보기`로 펼친다. AI는 판정을 올릴 수 없고(하향만) 이 사실을 화면에 적는다.
- **포트폴리오:** 총 평가금액·손익·현금·분산 정도 카드 → 한 줄 해석(쏠림·중복·현금) → 비중 도넛 → 업종 쏠림 막대 → 입력 폼 → (자세히) 보유 종목 표.
- **표는 스캐너(기회 찾기)와 상세 데이터에만.** 나머지는 카드.

## 상태 화면
- **로딩:** 무엇을 하고 있는지와 단계(`Loading what steps`)를 보여 준다.
- **오류:** 한국어 원인 설명 + `다시 시도` 버튼. 네트워크 오류·503·429는 GET에 한해 자동 재시도.
- **빈 상태:** 왜 비었는지와 다음 행동(`hint`).
- **시작 화면:** 백엔드 준비(`/api/health/ready`)가 될 때까지 대기 안내, 실패 시 원인과 재시도.

## 반응형
- ≥1280px: 3열, 900~1280px: 2열, <900px: 1열(사이드바는 위로). 핵심 카드(hero, 매수 계획)가 항상 먼저 온다.
- E2E 테스트(`backend/tests/e2e`)가 좁은 창에서 카드가 세로로 쌓이는지 확인한다.

## 접근성
- 색만으로 의미를 전달하지 않는다: 상승 ▲ / 하락 ▼, `+`/`!` 점 아이콘, 배지 텍스트(매수·관망·회피 등)를 함께 쓴다.
- 키보드 포커스 링(`:focus-visible`), `aria-label`(차트·막대), 모션 최소화 설정 존중.
