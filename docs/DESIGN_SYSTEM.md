# 디자인 시스템

구현: `frontend/src/styles.css`(토큰·클래스), `frontend/src/components/ui.tsx`(컴포넌트), `frontend/src/components/status.tsx`(상단 상태 표시줄).

**방향 (2026-09-28 개편)**
- 소유자가 쓰던 MarketHUD v5.28의 사용감을 따릅니다. 짙은 남색 배경, 보라 강조색, 둥근 카드를 쓰고, 판단 카드 왼쪽에 색 띠를 두며, 2×2 판단 타일·안전 리본·▸/▾ 펼침을 씁니다.
- 초보자용으로 글자는 키우고 한 카드의 정보량과 발광·그라데이션은 줄였습니다.
- MarketHUD의 계산·조건은 가져오지 않았습니다. 화면에 나오는 값은 모두 MarketLens 백엔드가 준 값입니다.

**색 규칙**
- 가격 상승·하락 색(`--up`/`--down`)은 매수·매도 판단 색과 섞지 않습니다.
- 상태는 색만으로 전달하지 않습니다. 모든 색에 단어나 기호(✓ ! ⛔ ▲ ▼ ●)를 함께 씁니다.
- 미국 시장 관행(상승=초록 계열)을 따르며, 혼동을 막기 위해 ▲/▼를 항상 붙입니다.

**대비 (WCAG, 계산값)**
- 캡션 `--muted`: 카드 위 6.8:1 (MarketHUD의 #747a8e는 4.3:1이었음).
- 주요 버튼 흰 글자 / `--accent-2`: 5.1:1 (MarketHUD의 #7668e8은 4.3:1이었음).
- 배지 글자 / 배지 배경: 5.9:1 이상(만료 배지).
- 모든 전경·배경 조합: 6.0:1 이상.

## 타이포그래피
- **글꼴:** Pretendard Variable. 앱에 포함해(`src/assets/fonts/PretendardVariable.woff2`) 로컬 파일로 불러옵니다.
  - 버전·출처: v1.3.9, npm `pretendard`, sha256 `9599f12f…82d900b4`.
  - PC에 설치됐는지와 관계없이 같은 모습입니다. `@font-face`는 같은 이름의 설치 글꼴보다 우선합니다.
  - 라이선스: SIL Open Font License 1.1. 원문을 `src/assets/fonts/Pretendard-LICENSE.txt`에 두고, 설치본에는 `licenses/Pretendard-OFL-1.1.txt`로 함께 배포합니다. ‘용어·판정 설명’ 화면에 링크가 있습니다.
  - 외부 CDN 요청은 없습니다(테스트 `src/design.test.ts`).
- **숫자:** 모든 숫자에 `font-variant-numeric: tabular-nums`를 적용합니다. 값이 바뀌어도 자리 폭이 흔들리지 않습니다.
  - 브라우저 측정(굵기 800, 20px): `$111.11`과 `$888.88`이 둘 다 85.39px입니다. 비례 숫자라면 63.97px와 83.11px입니다.
  - 숫자용 고정폭(monospace) 시스템 글꼴은 쓰지 않습니다. PC마다 달라지기 때문입니다.
- **줄바꿈:** `word-break: keep-all`(한국어 단어 단위).

## 화면 구조
- **상단 상태 표시줄(`StatusBar`, 항상 보임)**
  - MOCK/LIVE
  - 미국장 세션: 백엔드 거래소 달력 기준(휴장일·조기 마감 포함)
  - 뉴욕 시각과 한국 시각
  - 이 화면 가격의 기준 시각과 경과 시간(화면을 불러온 시각이 아님)
  - 분석 시각
  - 데이터 수집 진행률, 스캔 진행
  - 공급자 중단 수, AI 사용 가능 여부
- **첫 화면 순서:** ① 시장 분위기 → ② 검토 후보 → ③ 가장 큰 위험 → ④ 다음 핵심 일정 → 후보 카드(최대 5개).
  - 조건을 통과한 종목이 없거나 적어도 점수 상위 종목으로 채우지 않습니다.
  - 만료·재확인 필요·가격 조건 이탈 추천은 카드가 아닌 별도 목록에 둡니다.
- **종목 화면 순서:** ① 결론(판단 카드 + 2×2 타일: 현재가·최대 매수가·손절·가장 큰 위험) → ② 판단 이유(+ AI 요약, 결정론적 근거와 분리) → ③ 가격 계획(표 | 차트) → ④ 위험 → ⑤ 판단 철회 조건(가격 손절과 투자 논리를 분리) → ⑥ 뉴스·이슈·일정(기사 사실과 시스템 해석을 분리) → ⑦ 내 포트폴리오 → ⑧ 상세 자료(쉽게 보기에서 접힘).
- **창 크기**
  - 1280px 이하: 4열 → 2열.
  - 1100px 이하: 가격 계획 표·차트를 세로로.
  - 900px 이하: 메뉴를 가로로 바꾸고, 상태 표시줄 고정을 풀어 결론이 먼저 보이게 함.
  - 640px 이하: 1열.
  - Windows 125%·150% 배율은 CSS 픽셀 1536·1280 폭과 같게 동작합니다.

## 컴포넌트 (ui.tsx)
- **카드·배치**
  - `Card{title, icon, tone, explain, right, sub}`: 정보 묶음.
  - `Section{no, title, sub}`: 번호 붙은 구역 제목.
  - `Tile`: 2×2 판단 타일.
- **판단·상태 배지**
  - `Action`: 판단 배지. 만료된 매수는 취소선과 “만료”로 표시합니다.
  - `StatusBadge`, `Quality`, `Vetoes`
- **알림·상태 화면**
  - `Ribbon{tone, cap}`: 안전·데이터 권한 문제 전용 리본.
  - `StatePanel{kind}`: 10가지 상태를 설명합니다. 수집 중, 분석 중, 스캔 안 함, 후보 없음, 자료 부족, 오래됨, 가격 조건 이탈, 공급자 오류, AI 불가, 연결 끊김. 각각 “무슨 상황 / 알 수 없는 것 / 할 수 있는 일” 세 줄을 보여줍니다.
  - `StaleData`: 새로고침에 실패하면 이전 결과를 받은 시각과 함께 알립니다.
  - `Notice`, `Loading`, `Err`, `Empty`
- **펼침·용어**
  - `Disclosure`, `More`: ▸/▾로 펼칩니다.
  - `Term{k}`: 용어 설명 버튼. 클릭, Enter·Space, 터치로 열고 Esc나 바깥 클릭으로 닫습니다.
- **가격·차트**
  - `Change`: 가격 변화(▲/▼ + 부호).
  - `PriceLadder`: 손절·매수 구간·목표와 현재 위치.
  - `PriceChart`: 가격 계획선. 가까운 라벨은 서로 밀어 겹치지 않게 합니다.
  - `Donut`, `Bar`, `LineChart`
- **근거·신선도**
  - `EvidenceChips`, `FreshnessTable`
