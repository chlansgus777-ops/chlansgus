# SaveTicker 브라우저 연결 1.3.0

Chrome·Edge의 정상 로그인으로 받은 시장 정보를 이 PC의 MarketLens에 전달합니다. 뉴스 목록, 최근 기사 3건과 실적 검색 결과 2건의 본문 발췌·제공 요약·기업 연결·사용자 반응, 경제/Fed 일정, 리포트 목록 3건, 그리고 MarketLens가 알려 주는 후보 종목(한 번에 최대 10개, 종목마다 하루 한 번)의 옵션 집계를 선택합니다. 기사에 나온 종목이라는 이유만으로 옵션을 읽지는 않습니다. 비밀번호·쿠키·사용자 정보·개인 투표·작성자 계정은 읽거나 내보내지 않습니다.

1. MarketLens를 LIVE 모드로 실행합니다. 설정 → 데이터 연결 → SaveTicker의 **브라우저 연결 시작**을 누릅니다.
2. 만들어진 주소를 Chrome·Edge에서 엽니다. 내장 브라우저에서는 확장을 설치할 수 없습니다.
3. 안내 화면의 확장 ZIP을 풀거나 이 폴더를 사용합니다. chrome://extensions 또는 edge://extensions에서 개발자 모드 → 압축해제된 확장 로드 → manifest.json이 있는 폴더를 선택합니다.
4. 연결 안내 페이지를 새로고침하고 **이 브라우저와 연결**을 누릅니다. SaveTicker 탭에서 평소처럼 로그인합니다.
5. 설정에 **브라우저 뉴스 수집 확인**과 실제 건수·수신 시각이 표시되는지 확인합니다. 확장 등록 메시지만으로 수집 성공을 판단하지 않습니다. 보조 자료는 시장 → 이슈/일정에서 각각 수집 상태를 확인합니다.

이미 설치한 확장은 해당 폴더의 파일을 업데이트하고 확장 관리 화면에서 새로고침한 뒤 SaveTicker 탭을 새로고침합니다.

연결 직후 수집하고 뉴스는 약 2분, 상세·일정·리포트·옵션은 약 10분마다 확인합니다. SaveTicker 탭을 열어 두어야 합니다. 종료·절전·네트워크 장애·접근 거절은 수신을 지연시키거나 중단할 수 있습니다. 뉴스 5분, 보조 자료 15분 이상 새 응답이 없으면 이전 자료로 표시합니다. 뉴스 발행 시각·일정 시각·옵션 집계 날짜·수집 시각은 별도로 유지합니다.

보조 자료 수집 간격은 연결별 Chrome session storage에 유지합니다. MV3 백그라운드 작업이 종료됐다가 다시 실행되거나 같은 연결을 다시 눌러도 10분 간격을 초기화하지 않습니다. 이 저장소에는 로컬 자료 수신 키와 수집 시각만 있으며 SaveTicker 로그인 정보는 없습니다.

연결 주소는 24시간 동안 유효한 **로컬 시장 자료 전용 키**를 포함합니다. 다른 사람에게 공유하지 마세요. 계좌·설정·분석 저장·주문 권한을 주지 않습니다. 연결 해제·앱 재시작·브라우저 완전 종료 후에는 설정에서 다시 연결합니다. 확장 재설치나 SaveTicker 비밀번호 재입력은 통상 필요하지 않습니다.

서버 직접 이메일 로그인은 고급 설정에 남아 있습니다. 이 환경의 직접 요청은 HTTP 403 보안 검증으로 차단됐으며 비밀번호 오류로 단정하지 않습니다. 기본 연결은 정상 브라우저를 사용합니다.

SaveTicker 요약은 MarketLens 자체 AI와 구분합니다. 사용자 반응은 시장 전체 심리가 아닙니다. 실적은 원문에 실제/예상과 단위가 명시된 경우만 계산하고, 회계연도·조정 여부·누락 예상치를 추측하지 않습니다. 숫자로 구조화하지 못한 가이던스·부문 정보는 발췌로 확인합니다.

리포트 JSON에 읽을 수 있는 본문이 없으면 목록과 원 페이지 링크만 표시합니다. PDF/OCR, 개별 옵션 체인·IV·그릭스는 지원하지 않습니다. 옵션 집계의 전일 여부와 날짜를 표시하며 집계 기준 가격을 실시간 시세로 사용하지 않습니다. 헤드라인·조회수·사용자 투표를 투자 점수에 자동 가산하지 않습니다.

개발 검증: node --test integrations/saveticker-browser/extension.test.mjs
배포용 확장 ZIP 재생성: python scripts/package-saveticker-browser.py 후 프런트엔드 빌드.
