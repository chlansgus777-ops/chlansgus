# KTX 간편 예약 (Android)

Windows용 `app.py`(Python + Tkinter + korail2)를 안드로이드 네이티브 앱(Kotlin + Jetpack Compose)으로 옮긴 것입니다.
기능과 안전 규칙은 원본과 같습니다.

- 로그인(회원번호 / 휴대폰번호), KTX 성인 1~9명, 일반실 또는 특실
- 열차 조회: 매진 열차까지 표시하고, 시간 범위 끝까지 나눠서 조회
- 선택 열차 예약 / 자동예약(좌석이 있는 첫 열차 예약, 매진이면 1~3초 뒤 재조회)
- 모든 HTTP 요청 시작 간격 최소 1초. 결과가 불확실한 오류는 자동 재시도하지 않음
- 결제 기능 없음. 예약 후 코레일 앱/홈페이지에서 직접 결제
- 비밀번호, 회원번호, 토큰은 저장하지 않음(메모리에만 보관, 백업 비활성화)

안드로이드에서 추가된 점
- 자동예약은 포그라운드 서비스로 실행되어 다른 앱을 쓰거나 화면을 꺼도 계속됩니다(상단 알림 표시).
- 예약 성공이나 실패는 알림으로 알려줍니다. 알림 권한을 허용하세요.
- 예약 후 상세 조회에 실패해도 예약번호를 보여줍니다.
- 날짜는 달력에서 고를 수 있고, 출발역과 도착역을 바꾸는 버튼이 있습니다.
- 자동예약은 페이지를 받는 즉시 좌석을 확인해 바로 예약합니다(전체 조회 완료를 기다리지 않음).
- 목록에서 열차를 여러 개 선택하면 그 열차만 노리며, 조회 범위가 좁아져 같은 열차를 더 자주 확인합니다.
- 좌석 옵션 "일반실/특실": 일반실 우선, 없으면 특실로 예약합니다.
- 요청 간격 최소 1초는 그대로 유지합니다(계정 차단 위험을 피하기 위해).

## 설치

1. GitHub의 **Actions → ktx-android** 에서 최신 실행을 열고 `ktx-easy-apk` 를 내려받아 압축을 풉니다.
2. 휴대폰에서 APK를 열고 "출처를 알 수 없는 앱 설치"를 허용합니다.
3. 새 버전도 같은 키로 서명되므로 기존 앱 위에 그대로 덮어 설치됩니다.

요구사항: Android 8.0 (API 26) 이상.

## 구조

- `core/`: 순수 Kotlin 모듈. korail2의 로그인 암호화, DynaPath 토큰, 조회, 예약 API와 `app.py`의 조회·자동예약 로직
  - `CryptoTest`: 토큰, SID, 비밀번호 암호화 결과가 원본 Python 라이브러리와 바이트 단위로 같은지 확인
  - `KorailClientTest`, `BookingTest`: 모의 서버로 요청 형식, 쿠키 유지, 오류 처리, 페이지 조회, 자동예약 중지를 검증
- `app/`: Compose 화면(`MainActivity`), 상태 관리(`BookingController`), 포그라운드 서비스(`AutoReserveService`)

빌드: `./gradlew :core:test :app:assembleRelease` (JDK 17, Android SDK 35)

## 주의

비공식 API(korail2 포크 `dhfhfk/korail2@4b13426`)를 사용합니다. 코레일 서버 정책이 바뀌면 로그인이나 예약이
거절될 수 있습니다("앱을 최신 버전으로 업데이트" 등). 이때는 코레일 공식 앱을 이용하세요.
예약 오류나 응답 시간 초과가 나면 실제로는 예약이 처리됐을 수도 있으니, 다시 시도하기 전에 코레일 예약내역을 먼저 확인하세요.
